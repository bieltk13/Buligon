# Buligon — Site One Page (GitHub Pages corrigido)

## Opção 1 (mais fácil)
Baixe `buligon-site-arquivo-unico.html` e renomeie para `index.html`.
Envie somente esse arquivo para a RAIZ do seu repositório GitHub. Ele tem CSS, JS e imagens incorporadas.

## Opção 2 (arquivos separados, este ZIP)
Extraia o ZIP e envie TODO o conteúdo para a RAIZ do repositório: `index.html`, `css/`, `js/` e `assets/`. Não envie apenas o index.html. Não deixe tudo dentro da pasta `buligon-github-pages-corrigido` se o GitHub Pages estiver configurado em main / (root).

Em Settings > Pages selecione Deploy from a branch > main > / (root). Aguarde o commit ser publicado e recarregue com Ctrl + F5.

## Atenção
Este material é um protótipo comercial, não é o site oficial da Buligon. As imagens e a logo foram recortadas de uma arte gerada por IA e não são fotos oficiais. Confirme telefone, horários, serviços, nota e direitos de uso das imagens antes de publicar como site de cliente.
